# Switchboardapp MealMate

A lightweight meal planning web app.

## Features
- Add meals by name, category, calories, and ingredients
- Filter meals by category
- Auto-calculate total and average calories
- Auto-generate a shopping list from all meal ingredients
- Data persistence using browser localStorage

## Run locally
Open `index.html` directly in a browser, or run a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
